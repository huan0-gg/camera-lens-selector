# 相机镜头选型与精度计算工具

机器视觉工程用的单文件网页工具：填写检测需求，自动完成相机与镜头选型，并给出视野、精度、景深等关键参数的完整核算过程。

**在线使用**：直接用浏览器打开 `index.html` 即可，无任何依赖、无需后端。

## 功能

- **按视野选型**：输入工作距离、目标视野、最小检测特征、每特征占用像素 → 推荐 Top 3「镜头 + 相机」组合
- **按焦距验算**：给定镜头焦距与相机，反推实际视野 / 精度 / 景深，可对照期望值做合格判定
- **完整参数输出**：每像素精度（mm/px）、实际 FOV、景深近/远界、像距、放大倍率、弥散圆、超焦距、镜头解像力要求（lp/mm）
- **光路示意图**：随选型结果动态重绘的成像光路图
- **计算过程透明**：每一步公式都带入实际数值，可直接复制进选型报告
- **智能提示**：景深不足时自动反算所需光圈；高精度场景提示远心镜头；小特征场景提示畸变影响；广角/长焦端风险提示
- **典型场景预设**：手机壳划痕 / PCB 焊点 / 精密尺寸测量 / 大视野零件
- 支持复制选型报告、打印存 PDF；移动端自适应

## 计算模型

| 参数 | 公式 |
|---|---|
| 视野 FOV | `FOV = WD × 靶面宽 ÷ 焦距` |
| 每像素精度 | `精度 = FOV ÷ 横向像素数` |
| 需求精度 | `p = 特征尺寸 ÷ 每特征像素数` |
| 像距 | `像距 = f × WD ÷ (WD − f)` |
| 景深（超焦距法） | `H = f² ÷ (F# × c) + f`，`弥散圆 c = 2 × 像元尺寸` |
| 镜头解像力 | `≥ 1000 ÷ (2 × 像元尺寸μm) lp/mm` |

内置常见工业相机靶面（0.3MP ~ 20MP）与 C 口标准焦距（6/8/12/16/25/35/50/75 mm）库，推荐排序综合考虑覆盖倍率、分辨率成本与焦距通用性。
